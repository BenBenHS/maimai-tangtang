# 麦麦糖糖 · 教程跟练素材包

版本：2026-11-20。两期跟练：《麦麦起床》《再扫一遍》。

## 怎么用

1. 先看01_角色设定：本次指定的最新家居服三视图及六种表情对照。
2. 声线在02_声音参考；新家72张动画机位与最新版Blender工程在03_新家场景。
3. 跟练起床进入04_麦麦起床，采用第二版七镜与现有制作说明。
4. 跟练再扫进入05_再扫一遍，按图片顺序上传七张首帧，再使用本次保存的完整30秒提示词。

所有图片、声音和模型保持原文件。历史教程首帧用于复现当期镜头；当前角色与场景参考单独标明，不把不同阶段的图混成同一镜头。

本包提供现有素材和制作方案。已有生成短片的已知偏差、尚未生成的部分以及第三方装饰元素均在对应说明中标注。
