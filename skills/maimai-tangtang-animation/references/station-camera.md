# 地铁口实剪的运镜与节奏

依据《第二段细线条修复.mp4》，全长约 41 秒。时间为画面切点近似值，以下观察来自逐帧抽样。对白、音乐和音效落点待听音核对。

| 时间 | 画面怎样变化 | 可复用的做法 |
| --- | --- | --- |
| 0:00–0:03.8 | 街区仰景接街面全景，约 1.7 秒和 2.2 秒。 | 用两个简短的空间信息把人带进场。 |
| 0:03.8–0:12.6 | 先给糖糖近景约 4.7 秒，再切地铁口双人远景约 4 秒。 | 可以先抓表情，再补足两人和出口的空间关系。 |
| 0:12.6–0:16.6 | 取景沿麦麦身体上移，从腰身、衣褶和抬起的手，移到脸和眼睛。 | 让观众沿同一个构图逐步发现信息。计划这种镜头时先备有纵向余量的画面，标明起幅、落幅、落定后要留的动作。 |
| 0:16.6–0:20.5 | 硬切眼部极近景，画面主要变化落在目光和眨眼。 | 移动镜落定后，用固定极近景把动势收住，给细小表演留时间。 |
| 0:20.5–0:32.0 | 侧面双人近景、糖糖俯拍、麦麦单人，约 5、4、2.4 秒。 | 用景别与角度交接两人的反应。 |
| 0:32.0–0:41.1 | 糖糖沿街向远处走，回头停住。随后切麦麦接视线。远景尺度变化主要来自糖糖走远，建筑和树的位置相对稳定。 | 固定空间让人物走出纵深，等她回头再切到另一人的反应。 |

用在新戏时，优先借用「短建立空间 → 有目的的揭示 → 停下来读反应」。镜头时长随本集动作和实读调整。若只做到首帧，把计划中的运镜与已生成画面分开记录。
