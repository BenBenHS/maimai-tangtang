# 认识姐妹

本页依据已有“日常单元喜剧”制作说明整理，只是该系列的创作基线，尚非完整角色设定集。

| 角色 | 已有系列说明 |
| --- | --- |
| 麦麦 | 姐姐；冷静、慵懒、吐槽精准，表面嫌弃但会顺手参与。 |
| 糖糖 | 妹妹；元气、嘴硬、歪理多，擅长把心虚包装成生活哲学。 |

已有系列定位是每集30秒以内，用一个生活小事故展示姐妹的反差；典型节奏为快速建立事件、歪理升级、麦麦补刀、动作反转。这不是所有作品必须遵守的唯一格式。

## 可参考的已有制作主题

- 《健康零食》：已有第一集制作材料。
- 《我没睡》：已有说明将其列为正式第二集；糖糖嘴硬不困，麦麦顺手照顾睡着的妹妹。
- 《一句都没说》：已有说明将其列为正式第三集制作包；餐桌递物默契与冷吐槽。

“正式第二集/第三集”是旧制作说明中的编排，不代表已经完成或公开发布；最终状态待作者复核。

《买一送一》等旧废案不应被自动恢复成当前制作任务。
